## 📋 PASOS RÁPIDOS

### 1️⃣ **En Railway:**
1. Crear 5 servicios separados
2. Conectar cada uno al mismo repo GitHub
3. Copiar y pegar las variables de arriba
4. Agregar MongoDB addon a servicios 2, 3, 4, 5
5. Desplegar

### 2️⃣ **Configuraciones Build/Deploy:**
Usar archivos de `railway-services/` folder

### 3️⃣ **Después del deploy:**
Actualizar URLs entre servicios con las URLs reales que te dé Railway
